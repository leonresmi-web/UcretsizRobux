# Roblox temalı güvenli sürpriz sitesi

Bu klasörde GitHub Pages'e yüklenmeye hazır üç dosya bulunur:

- `index.html`
- `showcase.webp`
- `monkey.gif`

## GitHub'a yükleme

1. GitHub'da `leonresmi-web/leonresmi.github.io` repository'sini aç.
2. **Add file → Upload files** seç.
3. Bu klasördeki üç dosyayı birlikte seç.
4. Dosyaların repository'nin en üst seviyesinde görünmesini sağla; `assets` gibi başka bir klasörün içine koyma.
5. **Commit directly to the main branch** seçili kalsın.
6. **Commit changes** düğmesine bas.
7. GitHub Pages'in yayınlaması için birkaç dakika bekle.

Site hiçbir hesap, şifre, e-posta, ödeme veya kişisel bilgi istemez; başka siteye yönlendirme yapmaz.
